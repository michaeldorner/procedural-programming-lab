# Lab 01: The Zen of Python

**Topics:** IDE workflow, running scripts, running unit tests  
**Lectures:** 01 (Introduction to Programming & Python), 19 (Unit Testing)

Verify that your Python environment, editor, and test runner work together cleanly by displaying *The Zen of Python*.

## Requirements

- Ensure running `zen.py` prints *The Zen of Python* to standard output with no extra output.

## Worked Examples

- Running `python zen.py` prints *The Zen of Python, by Tim Peters* and its 19 aphorisms.


## Run & Test

```bash
python zen.py
python -m unittest
```
